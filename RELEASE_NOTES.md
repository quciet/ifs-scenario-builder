# Scenario Builder 0.4.2

- Integrates proposal review, confirmation, inspection, file preview and export into Companion's main conversation.
- Uses the main composer for revisions and optional .sce attachments, with no separate scenario chat destination.
- Saves confirmation results through the owning Companion conversation so reopening a task restores the latest draft.
- Retains installed IFs metadata validation, baseline defaults, semantic direction checks and group-aware writing.

Requires **IFsCompanion 0.3.5 or newer**. Update Companion first, then update this optional tool through Manage tools. Existing saved scenarios are preserved.
