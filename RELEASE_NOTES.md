# Scenario Builder 0.4.4

- Validates explicit parameter names and obvious meaning conflicts against the selected IFs installation before paid research. Missing names are suggestions requiring a user choice, never silent substitutions.
- Supplies verified dimensions, units, bounds and audited polarity together; preloads exact identifiers in follow-ups and supplies the canonical country list once. Compacts repeated group-baseline receipts while retaining target coordinates and values.
- Adds baseline-relative scaling computed locally for each country, subgroup and year, preserving actual saved Current Path differences instead of assuming every input starts at one.
- Feeds invalid proposals back to the AI with parameter, target, year and reference details when available. It can repair its own numeric, dimension or direction mistakes without asking users to repeat clear instructions. Repeated unsuccessful repairs pause with the request and candidate saved and a Continue action. Genuine missing assumptions and overlapping rules still require user input.
- Checks entries independently; opposite changes in different countries are allowed. Conflicting narrative phrases no longer become a global last-phrase direction rule. Numeric multiplier assumptions in clarification prose must be submitted for validation.
- Tracks reported and estimated AI usage through Companion's main chat, including failures and continuation. Inline reviews no longer duplicate the chat reply.

Requires **IFsCompanion 0.3.8 or newer**. Update Companion first. No fixed research-round cap is introduced; actual provider/context limits and no-progress detection preserve completed work. Saved scenarios, explicit confirmation and local compiler checks are retained.

# Scenario Builder 0.4.3

- Removes the fixed metadata research-round cutoff. Productive lookups can continue beyond the former limit.
- Detects repeated calls and identical results without new information, reuses cached lookups, and offers Continue or Revise with progress preserved.
- Saves complete metadata exchanges during research so an interrupted service can restore them. Stop, provider/format failures and actual context constraints still pause with saved progress.
- Retains main-chat review, explicit confirmation, local compiler validation, IFs baseline defaults and group-aware exports.

Requires **IFsCompanion 0.3.6 or newer**. Update Companion first, then update this optional tool through Manage tools. Saved scenarios are preserved. No confirmation or model-run approval is bypassed.
